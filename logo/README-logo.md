# logo —— zfs-tool

由本地 ComfyUI（Z-Image-Turbo 模型）生成的 App 图标。
风格约定：**深色近黑深蓝底 + 青蓝系渐变 + 扁平矢量 + 圆角方形底板 + 画面里不要任何文字**。

## 4 个候选（1024×1024，`compare.png` 是 2×2 拼图）

| 候选 | 思路 |
|---|---|
| `a-pool-disks.png` | 三层叠放的圆柱形磁盘盘片组成存储池 + 最上面一片上一枚对勾 |
| `b-terminal.png` | 圆角方形终端窗口 + 一行命令行提示符 + 三条长度不同的输出横线 |
| `c-tree.png` | **选中的**：顶端一个方块，折线分支向下连到三个小方块（数据集层级），底层一条横板（存储池） |
| `d-shield-disk.png` | 圆角盾牌里一枚正视的磁盘盘片（同心圆 + 中心点），表现数据池受保护 |

## 选中 `c-tree.png`，理由

1. **语义最贴 zfs-tool 本身**：ZFS 的核心就是 **pool → dataset 的层级树**，这幅图正是「一个上层节点分出三个子节点 + 底下一整条 pool 横板」，一眼就是存储池管理工具。
2. **符合风格约定**：扁平矢量、青蓝渐变、主体居中、留白均匀，**画面里没有任何文字**，缩到 48px 仍是「树 + 横条」的清晰轮廓（见 `preview-sizes.png`）。
3. **背景纯**：四角取色 `rgb(19,27,45)`，各点通道偏差 ≤ 2 ⇒ 合成圆角底板后边界无缝。
4. 淘汰理由：`a` 生成图**自带白色外底**（四角纯白 `rgb(252,252,253)`），取色合成会得到白底板 + 内部深色板 ⇒ 板中板；`b` 画面里**冒出了 "zfs-tool" 文字**，违反「不要任何文字」；`d` 四角白 + 背景花（通道偏差 243）。

## 各文件用途

| 文件 | 用途 |
|---|---|
| `a-*.png` … `d-*.png` | 4 个候选原图（1024） |
| `compare.png` | 4 个候选的 2×2 拼图（A/B/C/D 角标） |

| `logo.ico` | Windows 图标，内含 256/128/64/48/32/16 六档（zfs-tool 是 NAS 上的单文件 py 发行版，主要给本机快捷方式 / 文档配图用） |
| `preview-sizes.png` | 256 / 96 / 48 三种尺寸缩览（验收小尺寸是否还认得出） |
